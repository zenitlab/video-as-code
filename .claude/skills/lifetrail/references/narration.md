# 旁白写法：`narration/<who>/script.json`

时间轴由旁白驱动（`tools/build_timeline.py`）：旁白多长，画面就停多久。所以“详略得当”不是文风问题，而是直接决定成片节奏和时长。

## 文件格式

一个 JSON 数组，按片中出现的先后排列。每段都要有 `id`、`kind`、`text`。`id` 全片唯一，也是音频文件名（`narration/<who>/audio/<id>.mp3`）。

| kind | 额外字段 | id 惯例 | 在片中的位置 |
|---|---|---|---|
| `intro` | — | `intro` | 片名卡之后，全国俯瞰时讲；最多一段 |
| `milestone` | `step`：里程碑所在半年 | `m_<step>`，如 `m_1079H2` | 镜头推到事件地，停下讲完再走 |
| `span` | `from`、`to`：连续的非里程碑半年步 | `p_<from 的年份>`，如 `p_1057` | 覆盖的几步按旁白长度均匀拉长，边走边讲 |
| `outro` | — | `outro` | 片尾全程回放时讲；最多一段 |

示例（取自苏轼）：

```json
[
  {"id": "intro", "kind": "intro", "text": "他一生三次被贬，临终前把一生功业总结为三个贬所的名字。半年一步，我们重走苏轼的路。"},
  {"id": "m_1037H1", "kind": "milestone", "step": "1037H1", "text": "景祐三年十二月十九日，换算成公历是一零三七年一月八日，苏轼生于眉州眉山。……"},
  {"id": "p_1037", "kind": "span", "from": "1037H2", "to": "1055H2", "text": "他八岁入乡校，母亲亲自教他读书。十九岁，娶青神王弗为妻。"},
  {"id": "outro", "kind": "outro", "text": "六十四年，一百三十个半年。命运一次次把他推向远方，他却在每一个贬所，找到了生活。"}
]
```

## 硬约束（`build_timeline.validate` 和 `tests/test_timeline.py` 检查）

- **每个里程碑恰好一段 `milestone` 旁白**；`step` 必须是带 `milestone` 的步。原因：里程碑停留时长 = 旁白时长 + 余量，没有旁白就没有停留。
- **`span` 只能覆盖连续的非里程碑步**，不能与别的段重叠，**不能跨人生阶段**（阶段的第一步只能做 span 的起点）。原因：章节卡插在阶段第一步之前，跨阶段的旁白会被章节卡截断。
- 没被任何 span 覆盖的非里程碑步照常走（0.55 s，跨 500 km 以上 0.95 s），只有字幕没有旁白。平淡时期可以整段不讲。
- **非里程碑旁白占比 < 40%**：`(span + intro + outro 的旁白时长) ÷ 全部旁白时长`。片头、片尾也算在内；第一批只算了 span，按条款口径重算后毛泽东 0.445、苏轼 0.418 都超标，只好删掉约 68 s 和 35 s 旁白。已有六部在 0.21–0.38 之间，写的时候以 **≤0.35** 为目标留余量。
- **一级里程碑（importance=1）的平均旁白时长必须长于二级。**
- 每段旁白之间、字幕之间不重叠；每个半年步在画面上至少 0.4 s；里程碑停留至少 3 s（远途里程碑抵达后也要停够 3 s）。
- 总时长落在 `person.json` 的 `targets.duration_min` 内。
- 配音必须由当前文本和声线合成（按“文本 + 声线 + 语速 + 音调”哈希核对）。改了文本或声线就重跑 `python3 tools/tts.py <who>`。

## 三种段怎么写

**里程碑段：详讲。** 时间（年号 + 公历或月份）→ 地点 → 发生了什么 → 为什么重要。可以引一句原文，引文与卡片 `quote` 一致。一级里程碑讲清来龙去脉，二级一两句交代。已有六部的里程碑段在 6–78 s 之间，多数 10–25 s（约 35–100 字）。

**概述段（span）：略讲。** 一两句交代这一段时间在哪、做什么，为下一个里程碑铺垫。已有六部多为 14–49 字。旁白比覆盖步数 × 0.55 s 还长时，这几步会被拉慢，所以长 span（十几步）配短旁白最自然；只覆盖一两步的 span 尽量写短。

**片头 / 片尾：一句钩子，一句收束。** 片头给出这个人一生的主题（苏轼“三个贬所”），片尾在全程回放时总结（年数、半年数、一生的落点）。各 40 字左右即可，它们都计入非里程碑占比。

## 远途里程碑：边走边讲

满足以下条件的里程碑，镜头不先停下，而是整段边走边讲，走到终点再定格（至少 3 s）：

- 写了 `milestone.place` 的：该半年 `places` 有 **≥8 个**途经点（长征这一类）。
- 没写 `place` 的：途经点 ≥6 个，或这一步路程 >1200 km。

所以远途里程碑的旁白要**按行进顺序**讲路线（遵义会议 → 四渡赤水 → 金沙江 → 大渡河 → 泸定桥 → 夹金山 → 懋功会师），画面和讲解才同步；行进时长按旁白长度定（3–30 s），旁白太短路线会走得很快。

不是远途、但写了 `place` 的里程碑，镜头停在 `place` 讲完，再继续走该半年剩下的行程（开国大典在北京讲完，再出发去莫斯科）。旁白可以在末尾提一句后续去向。

## 节奏与长度估算

- 已有六部的语速约 **3.4–4.0 字/秒**（按 −4% 到 −16% 的语速设定，标点不计）。
- 旁白总时长约占全片的 **62%–87%**。估算：目标时长（秒）× 0.75 ≈ 需要的旁白秒数；× 3.5 ≈ 全片旁白字数。例如目标 8 分钟 → 约 360 s 旁白 → 约 1250 字。
- 写完先跑一次 TTS 和 `build_timeline.py`，看打印的总时长；超出区间就增删旁白（优先删 span 和片头片尾），**不要改 `build_timeline.py` 的常量**。原因：常量一改，所有人物的时间轴、配乐分段都会跟着变。
- 已有脚本把公元年份写成汉字（“一九三五年”“一零三七年”），数字和年号读法更稳定。生僻字（谡、巂、儋等）的读音无法自检，列入运行记录的“未验证”。

## 措辞

- **有争议的事实用审慎措辞**，和 `contested` 一致：“一说”“一般认为”“据《汉晋春秋》……《晋书》记为魏胜”“难以考证”“约在此时”“也有学者存疑”。不要把 `contested` 里的一说讲成定论（李白片头从“生于碎叶”收为“生于西域”，里程碑段再并列两说）。
- **不用演义、传说的说法**；传说必须讲时加“相传”。
- 立场措辞按阶段 0 的决定（如大陆通行史学表述、“总统”是否加引号）。
- 旁白、卡片副标题、引文说的数字和说法要一致（“十五年而成帝业”与旁白“十六年”曾同屏打架；“一住十年”与引文“至移三霜”不一致，后改为引李白自述“酒隐安陆，蹉跎十年”）。两种正史原文措辞同屏（本传“戮谡以谢众”与《马谡传》“下狱而死”）可以互补，但要确认确实都是原文。

- **里程碑旁白的第一句要从镜头所停的地点和事件讲起** —— 镜头在里程碑开始时就推到 `milestone.place` 并停住；如果第一句讲的是同一半年里另一处先发生的事，观众会看着 A 地听 B 地。同一半年有两件大事时，先讲停留地的这件，另一件用“此前”带出，或放到前后的概述段（粟裕 1948H2：镜头停在碾庄，旁白却先讲“九月攻克济南”，审片标为画面与旁白不符；改为先讲碾庄围歼，再以“此前九月”带出济南）。

## 三处同步

任何一条事实修正（来自核查、复审或审片），都要同时改：

1. **数据**：`data/<who>/steps.json` 的 `event`、`milestone.subtitle`/`quote`/`place`、`note`、`contested`（含 `adopted`）。
2. **旁白**：`script.json` 里这件事出现的每一段（里程碑段，以及片头、相邻 span、片尾里顺带提到的）。
3. **卡片**：卡片取自 `milestone`，回看标题、副标题、引文与新旁白是否仍说同一件事。

改完：`python3 tools/tts.py <who>` → `python3 tools/build_timeline.py <who>` → `python3 -m pytest -q tests -k "<who> and not music" -m "not env"`（阶段 5 写好 `music/<who>_stages.json` 之后改跑全量 `-k <who>`）。第二批有两处只改了旁白，事件条仍是定论口吻，是复审第二轮才发现的。
