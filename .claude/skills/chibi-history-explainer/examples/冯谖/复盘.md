- 第一版最静的是剖面图（挖完就不动）、结尾定格、分屏送东西。改了三件事：引擎给每个场景加一层从头到尾约 3% 的慢推（D1「每页都在慢推」）；剖面图挖完后兔子在窝里蹦、冯谖跳着欢呼、土粒往下掉；分屏两边都加动作，结尾问号一跳一跳。静止帧从 7% 降到 1%。
- 帧差中位数和动态帧还比 D1 低：D1 几乎每句都有整身大动作（冲、跳、翻），这条有不少「站着说话 + 道具出现」的页。另外 D1 是录屏，压缩噪点也会抬高帧差，数字不必追平，但动作量确实少。

## 对上了的
- 两组 ×1 ×2 ×3 首尾对称：弹剑唱歌三回（每回都有原文卷轴「长铗归来乎」）、狡兔三窟三个窝（剖面图里一个个挖出「薛」「齐相」「宗庙」）。魏国车队来请三趟也用了 ×N。
- 群戏补上了（张良那条的短板）：满堂三千门客（三排长案，远小近大，吃 / 聊 / 一起憋笑）、薛的百姓对借据 → 惊 → 欢呼万岁、离薛百里扶老携幼夹道（老人拄拐、孩子蹦）。
- 前因后果每件都在：为什么给鱼给车、为什么不唱了、为什么烧借据（买义）、为什么一年后百姓来迎、每个窝是什么。
- 新转场 / 版式：分屏（左边送东西给老母亲、右边冯谖放下剑，D1 的水火分屏）、「义」大字发光。
- 拟音：弹剑 `twang`、敲门、哄笑。

## 复盘时改掉的
- 弹剑页的思考气泡压三行字幕 → 气泡改画在屏幕坐标右侧，卷轴挪到左边。
- 「义」字黄色叠在同色光芒上看不见 → 加深色描边。
- 分屏左右两半的镜头中心算错，老母亲和冯谖被切 → 左半 translate(-480)、右半 translate(480)。
- 剖面图里挖洞的冯谖压字幕 → 镜头拉远（0.8）、地面压低。
- 高枕的头没落在枕头上；兔子挡住「薛」字。

## 还不如 D1 的

- 马和车还是简化侧影；剖面图里的兔子偏小。
