# 张良拾履 · Q 版小人讲解片

学抖音「韩愈三封求职信」（D1）的 Q 版小人风格，换成原创题材做一条：《史记·留侯世家》张良圯上拾履。
D1 的逐帧拆解在 `../拆解/同账号另两只/拆解结论.md` 的「三、D1 · 逐帧细拆」，做之前先读。**只学 D1，不带号舍 / 刘邦片的风格规则。**

## 文件
- `文案.md`：47 句文案（用户 2026-11-09 选定题材，11-10 加入后半生计策并补全前因后果）。
- `engine.js`：Q 版小人引擎。`chibi()` 部件拼装小人（头、发型 / 帽、脸、身体、袖手、脚、阴影），表情库、漫画符号（pop、青筋、冒烟、汗、扬尘、残影圈、速度线、呼气、音符）、原文卷轴、网页小标签、D1 版式字幕、叠化合成。
- `scenes.js`：第 1–5 句（0–25 秒，桥上）和公用的桥（分 night / predawn / dawn）、鞋、走路、handPos。
- `scenes_mid.js`：计策段的原始场景（峣关、鸿门宴、栈道、借箸、踩脚、封赏）和火、旗、栈道、筷子、封地图等道具。
- `scenes_mid2.js`：计策段补前因后果后的版本（138–226 秒）：MAP 把旧场景按新字幕重新分配时间，加新场景（入关中、荥阳被围）和陈平、算筹、气泡。
- `scenes2.js`：其余段落，以及全片的 SCENES、PAGES（字幕）、overlay、CUES（拟音表）。148 秒以后的旧段落用 `SH = 78` 整体后移。
- `props.js`：道具和场景（计数器、气泡、钱箱、铁锤、车马、通缉令、公鸡、竹简、黄石、帐篷沙盘、香炉、画像……）。
- `复盘.md`：和 D1 的复盘。
- `render.mjs`：`node render.mjs stills 1,2,3` 出截图；`node render.mjs video --out=名字` 出无声视频，并写 `out/cues.json`。
- `audio/mix.py`：按 cues 合成拟音，配乐用 `audio/C片bgm.m4a`（用户定：用 C 片 BGM，从号舍复制）→ `out/mix.wav`。不给配乐文件时退回合成的临时拨弦曲。
- `test.html` + `test_chars.js`：小人造型 / 表情单独测试页。
- `对比/`：和 D1 的逐帧对比图。

```
node render.mjs video --out=张良拾履_无声 --crf=22      # 约 13 分钟
uv run -q --with numpy --with scipy python -I audio/mix.py out/cues.json out/mix.wav audio/C片bgm.m4a
ffmpeg -i out/张良拾履_无声.mp4 -i out/mix.wav -c:v copy -af loudnorm=I=-16:TP=-1.5:LRA=11 -c:a aac -b:a 160k -shortest out/张良拾履.mp4
```
ffmpeg 要 7.x（支持 `-fps_mode`）。

## 已定的做法（从 D1 量的）
- 小人：头直径 D，头占身高约 47%；身体是上窄下宽的圆角梯形；垂手时没有胳膊、只有两只圆手；脚两团深色。张良用黑发 + 发髻 + 横簪 + 两条发带（代替 D1 的帽翅，同样会弹）；老头按《史记》「衣褐」穿褐色，秃顶白髻、白眉、长白胡子、拄拐。
- 构图：脚踩在画面下 10%，人占画面高约一半；推近时到 57%。
- 动作：蓄力 → 动作 → 过冲 → 回稳；身体整块倾斜、拉伸、压扁，配件（发带、胡子）晚一拍弹；表情硬切。
- 镜头一直在动：每页慢推，重点处推近，道具掉落时镜头跟着摇。
- 字幕左上，字号 68、行距 112、首行 y 150（复盘时按 D1 重量），浅蓝【】/ 红〔〕关键词 + 同色细下划线，逐字模糊出字；句中全角空格，句末不加标点。
- 出字不卡拍，动作配拟音。
