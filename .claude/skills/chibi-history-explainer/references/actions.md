# 动作库和场景模板

帧数按 30fps，来自 D1 逐帧（`拆解/同账号另两只/D1细拆/s_dash.jpg`、`s_jump.jpg`）和张良拾履的实做。代码位置：模板 `kit/template/scenes.js`，例片 `examples/张良拾履/`。

## 动作（拆法 + 帧数 + 写法）
| 动作 | 拆法 | 帧数 | 例子 |
|---|---|---|---|
| 冲门被挡 | 后仰蓄力 4 → 冲出 4（速度线）→ 接触 2（对方闪身，换「> <」）→ 弹回 4（扬尘）→ 回稳 ~10，对方脚下残影圈慢慢淡 | ~24 | 模板 s1 `HITS` |
| 跳起被弹飞 | 下蹲 2 → 起跳 4（身体竖拉 1.3 倍）→ 后翻飞出 12（整体转、走抛物线）→ 落地压扁 2 → 帽子晚一拍转着落 12 → 冒金星 | ~45 | 模板 s1 `JUMP`；例片 sDawn2 甩袖扇飞 |
| 踢东西 | 后仰 -0.26 rad 4 帧 → 前踢 +0.2、脚伸 0.5D 3 帧 → 东西沿抛物线飞出（带三个残影）→ 回稳 | ~16 | 例片 scenes.js 踢鞋 |
| 举拳要打 | 后仰蓄力 + 压扁 → 拳甩到头顶（eback 过冲）→ 拳一直抖（`shake`）+ 青筋 + 冒烟 + 脸红 | 蓄力 5、挥 5 | 例片 10–12.7 秒 |
| 泄气 / 忍了 | 拳慢慢放下 → 吐一团气（`puffCloud`）→ 身体压扁到 0.88 再回 0.97 → 汗 → 低头走开 | ~30 | 例片 12.7–15 秒 |
| 喷饭 | 后仰蓄力 → 前倾 + 白点喷射（`spray`）→ 跳脚骂（三下小跳 + 冒烟） | 蓄力 8 | 例片 sMeal |
| 踩脚 | 伸脚 0.15 秒到位（脚放大 1.7 倍 + 浅色鞋底，`stompL/R`）→ 对方弹起一下换「> <」→ 镜头猛推到脚下再拉回 → 两人凑到耳边 | ~20 | 例片 sStep |
| 甩袖 | 手往回收 → 一甩到 2.3 rad → 对方后翻飞出画 | ~12 | 例片 sDawn2 |
| 走路 | 每步身体一颠 + 两脚交替 + 左右轻摆，`walk(o, 走过的距离, 步长)` | 每步 ~8 | common.js |
| 跑 | 同走路，步长缩短、前倾 0.15–0.2、身后速度线、停下扬尘 | | 例片 sDawn1 |
| 跪 / 坐 | `kneel(o, k)`：sy 压到 0.74、前倾 0.14 | 起落 ~8 | 例片 15–25 秒 |
| 说话 | 嘴每 1/8 秒在 O / small 之间换，配合 2–3 下小跳 + 手往前戳 | | 例片老头「孺子下取履」 |
| 点头 / 鞠躬 | lean 来回 2 次 0.13 rad | 每下 ~6 | |
| 惊到 | 「!」弹出 + 原地蹦 0.12–0.3D + 发带 / 帽翅弹 + 眼睛换 wide | ~8 | |
| 想 | 头顶一串小圆点 → 云朵气泡弹出（eback） | ~8 | `bubble()` |
| 消失 | 雾层升起 + 本人 alpha 渐隐 | ~40 | 例片 sMid |

通用：`strike(t, t0, 蓄力量, 动作量)` 给出一条「蓄力→动作→过冲→回稳」曲线；`spring(t, t0, 幅度)` 给配件的晚一拍弹；`eback` 缓动做过冲。

## 转场
- 推近 + 叠化：引擎默认（`XF = .4`），场景切换点前 0.4 秒自动叠。
- 道具飞屏：例片 `flyIn()`（竹简转着放大到填满 → 从中间裂开两边滑走）。
- 黑旗扫过：`blackFlag(t, k)`（改朝换代）。
- 时间不同的同一地点：换 `bridge` 的 `tod`，叠化。
