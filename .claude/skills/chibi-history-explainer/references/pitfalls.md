# 坑（张良拾履踩过的）

| 现象 | 原因 | 办法 |
|---|---|---|
| 人看着比原片小、片子不如原片 | 照桥的全景构图，脚在画面 65% 高 | 脚踩画面下 10%，人占画面高一半；道具掉到画面外就让镜头跟着摇 |
| 动作看着「轻轻一歪」 | 幅度照常识给，没对原片数值 | 后仰 0.26 rad、前冲 0.2、起跳竖拉 1.3 倍、蹦 0.3D；对照 15fps 逐帧 |
| 道具（鞋）看不清 | 暗色小物件在暗底上 | 放大 1.8 倍、加浅色鞋底和高光、加三个残影 |
| 字幕比原片小 | 量了字高 | 量字宽：一行 N 字的宽度 ÷ N |
| 老头的头发灰、像半透明 | 字幕背后压暗的柔光只填了一个矩形，边切过人头 | 压暗用径向渐变填全屏，半径控制在字幕区 |
| 三行字幕压住人头 / 气泡 / 弹字 | 字号改大后第三行到 y≈380 | 弹字、气泡、标签放 y > 420；栈道那种远景人物镜头往下压 |
| 踩脚看不出踩 | 两只脚都是暗地板上的暗色小块；「踩」字盖在脚上；矮桌挡住脚 | 踩人的脚放大加鞋底（`stompL/R`）、扬尘、残影圈；字挪开；桌子放人身后；镜头推到脚 |
| 胡子歪 | 看旁边时嘴偏、胡子不偏；小胡子斜椭圆压嘴角；高冠的冠绳穿过脸；白胡子摆幅太大 | 胡子随 look 偏移；小胡子画成嘴上方对称短弧；去冠绳；摆幅 ×0.12 |
| 封面竖版右边一条接缝 | 封面画布 1080 宽，场景背景按 W 铺（W 变 1080） | 竖版用 1920 宽画布画，截图时 clip 中间 1080 |
| 弹字落在别人头上 | 在场景外层按固定坐标画 | 在场景函数里按人物 `x` 画 |
| 拟音和画面错位（改稿后） | 场景时间拉伸了，拟音没换算 | 拟音时间走同一个 `unmap` |
| 背景命令被安全检查拦 | 一条 shell 里嵌套循环 + 子 shell 判断，检查器解析不了 | 拆成几条简单命令 |
| 思考气泡 / 弹字压三行字幕 | 气泡用世界坐标，镜头一推就飞到字幕区 | 和镜头无关的气泡放到 overlay 里用屏幕坐标画（冯谖 `songBubble`） |
| 分屏两半人物被切 | 半边 clip 后镜头中心还是全屏中点 | 左半 translate(-W/4)、右半 translate(+W/4) 再 camera |
| 黄字在光芒上看不见 | 同色叠加 | 大字加深色描边再填色 |
| 用了别的项目里的函数（sparkles、goldCake）报错 | 函数在另一个 skill 或例片里 | 拷到本项目的时间轴文件里 |
| 全片动态比样片低很多 | 样片是动作密集的开头；后面剖面图、定格、站着说话的页不动 | 每个场景自动慢推（`PUSH`）；挖完 / 说完后也要有小动作；按 5 秒一段量动态找最静的段 |
| 三回重复的段落单调 | 同机位同姿势，只换气泡内容 | 一回一个场景、一回比一回大（见 workflow「重复段落要升级」） |
| 拟音像「气音」、笑声假 | 用噪声凑脚步 / 嗖 / 纸；合成人声 | 卡通音效用有音高的合成，人声和自然声用真实录音（style-rules「声音」） |
| 唱词飘进字幕区或飘出画面 | 用世界坐标，镜头一推就变位 | 屏幕坐标画在 overlay 里，固定在人物旁、字幕下方 |
| Commons 接口返回「too many requests」 | 短时间查太多 | 放慢；文件直链按 md5 规则拼（upload.wikimedia.org/wikipedia/commons/a/ab/文件名），不走接口 |
| 片子拖 | 改稿时把旧动画拉长 | 拉长超过 1.5 倍的段落补动作（呼吸之外再加小动作） |

## 史实
- 写人物片之前列一生大事和时间，按比例分篇幅。
- 每件事写因果；原话挂卷轴写出处（篇名）；白话字幕不冒充原文。
- 秦汉人物不戴唐代幞头：张良用发髻横簪，官员用高冠，秦兵用盔（片尾注「人物和场面都是示意」）。
- 发布前逐句对原文。
