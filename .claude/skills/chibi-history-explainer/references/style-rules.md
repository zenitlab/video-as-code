# 风格规则（全部从 D1「韩愈三封求职信」逐帧实测）

参照片：抖音「韩愈三封求职信」（D1）。像素都按原片内容区 784×441 量，括号里是 1080p 换算（×2.45）。

## 小人（`engine.js` 的 `chibi()`）
- 头：正圆，直径 D。头底在脚上 1.04D，头顶 2.04D，帽子再高约 0.08D，**头占身高约 47%**。米白皮肤，粉色软边腮红在眼睛外下方。
- 五官：眼睛在头的 55% 高度，两眼间距约 0.35 头宽；粗黑线；嘴很小。表情换的是五官，头不动，**一帧硬切**，不做渐变。
- 身体：上窄下宽的圆角梯形（上 0.55D、下 0.98D），头压住身体上沿，有一道头的投影；腰带在身体 55% 高。颜色分身份。
- 手：**垂手时没有胳膊**，两只圆手贴在身体前面（`arm = undefined`）；比划时才出喇叭袖（`arm = 角度`，0 朝下、π/2 水平向外、π 朝上）。
- 脚：两团深色，大半被袍子挡住；走路交替抬。
- 头饰是会弹的配件：D1 的帽翅、张良的发带和横簪、老头的白胡子。**配件晚一拍弹**（`spring()`）。
- 质感：平涂 + 上暗下亮 + 细颗粒（4 张噪点轮换）+ 脚下软阴影（离地时变小变淡）。

已有的头饰（`who`）：`zl` 发髻横簪发带、`old` 秃顶白髻（自动带白长须）、`guard` 官帽帽翅、`king` 金冠、`guan` 高冠、`qin` 秦盔红缨、`xy` 项羽盔（金边长缨）、`strong` 红头巾、`lb` 竹皮冠、`smq` 小冠。胡子 `beard`：`black` 络腮、`goatee` 山羊胡 + 两撇小胡子。

## 表情库（`face: { eye, mouth, look }`）
- eye：`dot` 常态 · `wide` 白眼圈加黑瞳（惊）· `xx` 「> <」（挨打、用力）· `smug` 平眉压眼（得意）· `happy` 「^ ^」· `line` 「— —」（无语）· `close` 闭眼笑 · `angry` 斜眉 · `tight` 憋。
- mouth：`small` · `o` · `O`（张大）· `smile` · `smirk` 坏笑 · `grin` D 型大笑 · `wave` 波浪（怕、冷、委屈）· `grit` 咬牙 · `flat` · `frown` · `puff` 鼓腮。
- `look: [x, y]` 眼睛看的方向；嘴和胡子会跟着偏一点。`flush` 脸红（生气）。

## 构图
- 侧面舞台：地面一条横线，**脚踩在画面下 10%，人占画面高约一半**（近景），推近时到 55–60%。远景缩小但不变形。
- 每个场景至少一个暖光源（灯笼、蜡烛、门洞、窗光）+ 大块柔光晕，四角压暗。
- 暗褐底为主；天亮、黎明前换天色（`skyFor()`）。

## 动作（详见 `actions.md`）
- 一句字幕把动作**完整演出来**：「挡了三回」就真挡三回，右上 ×1 ×2 ×3 跟着接触时刻出。
- 每个动作「蓄力 → 动作 → 过冲 → 回稳」，**蓄力和回稳比动作本身长**；身体是一整块刚体，靠倾斜、位移、竖向拉伸压扁表现，不弯腰不曲腿。
- 小人从不完全静止：呼吸起伏约 1.5%、走路颠、配件晃。实测帧差中位数 0.81、静止帧 1%。

## 镜头和转场
- 镜头一直在动：每页慢推约 2–4%；重点处快推 1.5–2 倍（踩脚推到脚下）；道具掉落时镜头跟着摇。
- 换场：推近 + 0.4 秒叠化（最常用）；拉远 + 叠化；**道具飞屏**（信封 / 竹简转着飞向镜头填满，再从中间裂开）；同形叠化；分屏。全片硬切 ≤ 3 个。

## 字幕
- 左上粗宋，**字号 68（1080p）、行距 112、首行 y 150、左边距 66**，一屏 2–3 行；背后一团深色柔光压底。
- 关键词两色：**浅蓝** 信息（人名、地名、数字），**红** 结论 / 反转；下面一道同色细下划线，两头淡出。红词落定后再鼓一下发红光。
- 逐字模糊放大出字（每字错开 0.04 秒，0.28 秒落定）；一页一屏，整屏模糊淡出换下一页。
- 用户规矩：句中全角空格断句，句末不加标点。（D1 原片有逗号句号，不照搬。）
- 节奏是阅读速度：每页中位 5.3 秒，**出字不卡拍**（实测拍上比例 0.26，随机 0.25）。

## 声音
- BGM 只铺底，不卡拍。
- **动作配拟音**，按 `CUES` 摆。`kit/audio/mix.py` 里分三类（冯谖片用户两轮反馈后定的）：
  - **卡通音效用有音高的合成**：脚步 `step2`（木头嗒嗒）、`whoosh2`（下滑咻）、`deflate2`（滑哨）、`drum`（低音鼓滚奏）、`anger2`（咚 + 上蹦）、`hop` `pop` `blip` `thud` `tock` `fall`。**不要用纯噪声凑**（旧的 `step` `whoosh` `deflate` `rumble` `paper`），用户说听着像「气音」。
  - **金属声用不协和泛音合成**：弹剑 `sword`（铮——嗡）、敲门 `knock2`、咳嗽 `cough2`。
  - **人声和自然声用真实录音**：笑声、欢呼、纸、火。合成人声笑用户直接说「不行」。录音放 `audio/samples/`，CUES 写 `smp:文件@起点:时长`。kit 里已带 7 个（Commons 上 CC BY 3.0 / 公有领域，署名见 `kit/audio/samples/来源和授权.md`，**发布时简介要署名**）。要新录音先问用户再下载。

## 版式小件
- 右上 ×N 计数（`countX`）、滚动数字（`countRoll`，到终值变红加波纹）。
- 原文卷轴（`scrollV`）：竖排原文，关键字红，底下一行小字出处。每句古文原话都挂。
- 网页小标签（`tag`）：左边一条金竖线 + 小字，交代人名地名。
- 思考气泡（`bubble`）：一串小圆点 → 米色云朵，里面画回忆或推理（第八条、留县相遇）。
- 漫画符号：`pop`（! ? 哼 咳 噗）、`vein` 青筋、`steam` 冒烟、`sweat` 汗、`stars` 金星、`dust` 扬尘、`ring` 残影圈、`speedLines`、`puffCloud` 呼气、`notes` 音符。
- 右下小字「人物和场面都是示意」。
