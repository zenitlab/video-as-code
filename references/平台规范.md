# 平台规范：抖音 / 小红书 / 视频号

同一支竖屏片要发多个平台时读这一篇。三个平台的界面遮挡不同，**同一套画面按平台缩放、平移出三个版本**，不要只交一个文件到处发。

坐标都按 1080×1920 成片算。数字来自 2026-10-21《AI反诈老太太科普》：小红书版先按抖音排版被用户否了（「小红书 内容设置不合理」，附手机预览截图），按下面的数字重排后用户确认「可以了」。

## 一、三个平台的遮挡

| | 抖音 | 小红书 | 视频号 |
|---|---|---|---|
| 顶部 | 状态栏 + 推荐/关注，到 y≈230 | 返回 / 搜索按钮，到 y≈230 | 状态栏 + 返回，到 y≈170 |
| 底部 | 账号 + 文案，从 y≈1440 起 | 账号栏 + 点赞/收藏/评论，从 y≈1560 起 | 文案 + 浮评，从 y≈1500 起 |
| 右侧 | 点赞/评论/分享按钮，宽约 160 | 底栏里，不压画面 | 按钮宽约 150 |
| **左右裁切** | 无 | **长屏手机上铺满屏幕高度，左右各裁约 100px** | 无 |
| 核实情况 | 多支片子发过 | 用户手机预览截图核实 | 公开资料 + 抽帧，用户未提异议，**还没有真机截图核实** |

小红书最容易踩坑的是左右裁切：9:16 视频在 19.5:9 的手机上会按高度铺满，两边被裁掉。按抖音全宽排版时，标题、来源小字、「情景演绎」这类贴边的字会被切掉一半。

## 二、排版参数

画面先按抖音写：内容放在 y 236–1450、x 54–1026，字幕在 y 1470。其他平台在 `src/Promo.tsx` 里整体缩放、平移，场景代码不用改。

| 平台 | 内容缩放 | 内容顶边 | 字幕 | 内容实际范围 |
|---|---|---|---|---|
| 抖音 `Promo` | 1 | 236 | 跟着内容，y 1470 | x 54–1026，y 236–1450 |
| 小红书 `PromoXHS` | **0.86** | **280** | **单独放：y 1440，x 120–960，字号 50** | x 122–958，y 280–1325 |
| 视频号 `PromoWX` | 1 | **196** | 跟着内容，y 1430 | x 54–1026，y 196–1410 |

- 小红书的字幕不跟内容一起缩：缩完的字幕太小，所以单独排在内容下方、账号栏上方。
- 背景（`Paper`、`Cork` 这类铺满画面的底）要铺出画面外 400px，否则缩放或平移后边缘会露出浅色底。写法：`top: -400, left: -400, width: "calc(100% + 800px)", height: "calc(100% + 800px)"`。用 `inset: -400` 或 `right / bottom: -400` 不行，会被 `AbsoluteFill` 的宽高压回画面大小。
- 来源小字、「情景演绎」这类标注不要贴着漫画格或照片的边，放在格子下方，各平台都安全。

模板已经带了这套参数：`template/src/lib/platforms.ts`，`Promo` 的 `platform` 属性，`Root` 里的 `PromoXHS` / `PromoWX`，以及 `npm run render:xhs` / `render:wx`。

## 三、检查

```bash
node scripts/stills.mjs --scenes --comp PromoXHS && python3 scripts/platform_check.py xhs
node scripts/stills.mjs --scenes --comp PromoWX  && python3 scripts/platform_check.py wx
```

`platform_check.py` 按上表把截图裁成手机上实际看到的样子：小红书左右各裁 99px，再把顶部、底部、右侧按钮的遮挡区压暗，拼成 `out/platform-<平台>.jpg`。逐张看：标题、数字、来源、字幕有没有被裁或被压住。

`check_video.py` 只查规格和响度，看不出遮挡，所以这一步不能省。查完请用户在手机上用「仅自己可见」或草稿预览一次。各平台的界面会改版，以真机截图为准；用户发来截图时，把新的遮挡位置更新到第一节的表里。

## 四、交付

| 平台 | 视频 | 封面 | 标题 |
|---|---|---|---|
| 抖音 | `宣传片 竖屏.mp4` | 竖 `封面 3比4.jpg`（或 9:16）+ 横 `封面 4比3.jpg` | 30 字内 |
| 小红书 | `宣传片 小红书.mp4` | `封面 3比4.jpg` | 20 字内，可带 emoji |
| 视频号 | `宣传片 视频号.mp4` | `封面 3比4.jpg`（按 3:4 居中显示） | 单独的标题栏，**16 字内**（含标点，2026-10-22 用户发布时实测） |

- 抖音的横封面会出现在电脑端和搜索结果里。不要让平台从竖封面里自动裁，自动裁会把标题切掉。横封面要单独排一张，标题放左边、主体放右边。
- 三个平台都要声明「内容由 AI 生成」：抖音在「自主声明」，小红书在「高级选项 / 内容声明」，视频号在「声明」。
- 发布文案三个平台各写一版，放在 `发布文案.md`。小红书正文适合用 📌 列要点；视频号要短。
