# 讲解设计：一句旁白出来时，画面拿什么让观众懂

知识科普、原理讲解、深度解读类的片子（`#vibe知识大赏`、特斯拉深度版这类），好坏不在配色和特效，而在**旁白说到的每一样东西，屏上都认得出、看得见它在变**。宣传片的功能段落同样适用：讲一个功能怎么工作，就是讲一个机制。

> 方法参考自 [vibe-knowledge-film](https://github.com/HeyChengC/vibe-knowledge-film)（HeyChengC，方法说明为 MIT 许可），按本工具「有旁白、竖屏优先、真实素材为主」改写。它附带的参考片拆解（`references/analysis.md`、`prompts.md` 第二节、`examples/stim_B`、`info_C`）版权属于原片作者，**不要照搬进任何片子**。

## 〇、配图和讲解的区别

**配图**：画面换给任何一段旁白都成立。一串发光的点、几根柱子、一个圆圈加标签「红细胞」——每句都「有画面」，看完的人仍然不知道东西长什么样、坏在哪。

**讲解**：屏上的东西叫得出日常名字、长得像它本身，旁白里的动词在屏上真的发生，看完能讲出「因为……所以……」。

特斯拉深度版里能当正面例子的：「推进器靠反作用力推车」配的是车尾喷气、车往前走的动画；「轮胎抓地力有上限」配的是驱动力条越过上限、轮子打滑冒烟。只配一张「80 千牛」大字的地方，就是配图。

## 一、六种画法

分镜表里每一句旁白都选一种：

| 画法 | 做什么 | 用在 |
|---|---|---|
| **亲自试** | 屏上摆出一个东西让观众自己起反应，旁白晚半拍说出观众刚想到的 | 开头钩子、一切「你以为……」 |
| **照着句子画** | 句子里说到什么屏上就是什么，动词真的做 | 讲事件、举例子、摆事实 |
| **当场做一遍** | 拿一个最小的具体题目，把方法一步步走完，状态和计数看得见 | 讲方法、机制、「为什么一定是这样」 |
| **并排比** | 两样东西放进同一个版式，只留一处不同 | 一切「A 比 B」、前后对比 |
| **摆到一张图上** | 把前面出过场的东西摆进一张图，轴用人话写 | 回答「为什么」，一条片最多两三次，一定在例子之后 |
| **只上字** | 规则、命名、结论、引文、金句；或者把上一幕停住 | 见第二节 |

另有两个贯穿动作：**回场**（开头的画面、道具在后面再出现，只改一处）和**合体**（把讲的东西和观众生活里的东西放进同一个画面）。

## 二、什么时候画，什么时候不画

能画的尽量画，但**大约每五句有一句不配新画面**——那是观众把刚看到的东西想明白的时间。

| 这句旁白在做什么 | 怎么处理 |
|---|---|
| 讲一件事、举一个例子 | 照着句子画 |
| 讲方法、机制、「因为……所以……」 | 找一个最小的题目，当场做一遍 |
| 说观众自己的直觉 | 让他亲自试 |
| 比较两样东西 | 并排比 |
| 说一个数量 | 让它数得出来（一格一格、一颗一颗，或一把全片通用的尺子），不是给数字配一根柱子 |
| 总结「为什么会这样」 | 摆到一张图上，用前面出现过的东西 |
| 提问 | 不加新画面：停住上一幕，或只留一个问号 |
| 起名字、下定义、结论、金句 | 只上字，前面的道具可以围在旁边 |
| 某年、某人、某篇论文 | 一行小字贴在已有画面上，不为它换场 |
| 过渡句 | 不画，让下一幕进场 |

容易犯的：

- **刚演过的事，结论句不要再画一遍。** 再配一张图表，等于不相信刚才那一幕。
- **没有东西可指的句子不要硬配图。** 态度、判断、过渡，硬配出来的就是光点、连线和抽象图形。
- **一个场景撑 2~5 句旁白，每句只改一处。** 不是每句换一个新版式。（和 AGENTS.md「单场景 ≤ 2 小节」不冲突：同一场景里每 1~2 小节都有一处新变化即可。）

## 三、怎么给一个概念找形象

对每个概念按顺序问，前面有答案就停：

1. **它本身是个东西吗？** 画它本身（真实截图、官方照片优先，其次代码画），要一眼认得出。
2. **它是一个过程或方法吗？** 找一个小到每一步都画得出的题目，走一遍。
3. **它是一个量、一种程度吗？** 给它一把尺子，用同一把尺子量三样东西。
4. **它是观众脑子里的事吗？** 设计一个五秒钟的小测试，让它当场发生。
5. **它是一条规律吗？** 先画两三个例子，再摆到一张图上。
6. **都不是**（判断、态度、总结）：不画，上字。

找到以后再加三问，把形象做强：

- **观众在生活里哪儿见过它？** 找那个锚。找不到锚的概念记不住。
- **换一个尺度看是什么样？** 拉近或拉远一级，原因和结果常常就连上了。
- **它坏了会怎样？** 让它错一次。正常时看不出它在干活，坏了才看得出。

### 画得像它本身

- **有体积，有材质**：明暗、高光、厚度。一个圆圈加一个标签不算画了那样东西。
- **从观众认得的地方进场**：先给一个人人见过的画面，再推进去找到要讲的东西。
- **记号只当小字用**：箭头、虚线框、柱子可以贴在东西旁边做说明，不能自己当主体。
- 原理示意图要标「示意图非实际比例」。

## 四、每一镜过三问

遮住字幕和小字，回答：

1. **屏上这是什么？** 用一个日常的词回答（一台车、一个气瓶、一条数轴、一张聊天截图）。答案是「一些点」「几条线」「几根柱子」的不合格。
2. **它在干什么？** 用一个动词回答，就是旁白里的那个动词，或它的直接后果。
3. **观众因此明白了什么？** 一句话，和上一镜明白的事不一样。

## 五、旁白和画面一起写

画不出来，多半是旁白的问题：句子里没有东西。先给每个概念找到形象，再把形象里的东西和动作写进句子。

| 画不出来的句子 | 找到形象以后 |
|---|---|
| 它的加速能力非常强。 | 车尾四个喷口一开，零到六十英里，现场跑出零点八一秒。 |
| AI 可以帮助打击诈骗。 | 骗子让它转账，它说好；真到输密码，它开始找老花镜。 |

## 六、分镜表

写在 `需求确认.md` 末尾。表前写清：一句话论点；全片的那个形象；那把尺子；哪几镜回场；每种颜色的意思。

| # 时间 | 旁白 | 画法 | 屏上是什么，在干什么 | 屏上的小字 | 观众明白了什么 | 素材 |
|---|---|---|---|---|---|---|

- 「画法」填第一节六种之一，或「停住 / 回场 / 合体」。
- 「屏上的小字」是这句的证据：数字、名字、出处，一镜最多一条。
- 表后写清：屏上所有的数怎么来的；哪些是示意。

写完自查：

- [ ] 遮住「旁白」一列，只读「屏上是什么，在干什么」，看得出在讲什么。
- [ ] 每句旁白里的名词，屏上找得到。
- [ ] 「只上字 / 停住 / 不画」约占五分之一（一个没有 = 把结论也画了；占一半 = 没找到形象）。
- [ ] 没有哪一镜的画面换给另一段旁白也成立。
- [ ] 说得出全片哪一下最让人「哦——」，它之前有铺垫、之后有停顿。

## 七、看图改图

| 看图时发现 | 多半是因为 | 改法 |
|---|---|---|
| 主体小小缩在中间 | 尺寸按「画得下」定的 | 先定屏上大小：主体占画面宽六成以上，再反推缩放 |
| 遮住字幕看不出是什么 | 画成了记号 | 加体积材质，或从认得的画面推进去；还不行就换形象 |
| 旁白说到的东西屏上没有 | 分镜漏了这个名词 | 画出来，或改句子 |
| 一句旁白里画面变了三四处 | 贪多 | 拆成两句，或删次要的 |
| 连着几句画面没变 | 没给每句找到那「一处变化」 | 回分镜表，每句写清改哪一处 |
| 转场中间几帧说不清在干什么 | 两个状态直接插值 | 换成一个说得出名字的动作（钻进去、卷起来、卡上去），或压到半秒内 |
| 推拉镜头先平移后猛冲 | 缩放在线性空间插值 | 缩放在对数空间里走，焦点按 1/缩放 走 |

改的时候守三条：**看图不看代码**；**动的地方看动的**（转场前后各抽几帧）；**拿成片当尺子**（和已交付成片、参考片并排比）。
