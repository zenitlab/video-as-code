# 风格方向与叙事结构菜单

这是**菜单，不是默认值**。每个产品都要根据它的气质、受众和素材重新组合，并由用户看过样帧后拍板。可以混搭，也可以自创菜单外的方向。

选方向时先回答三个问题：
1. **产品的气质**是什么？（专业可靠 / 年轻好玩 / 高端克制 / 极客硬核 / 温暖陪伴）
2. **最有说服力的素材**是什么？（真实界面截图 / 做出来的作品 / 数据 / 用户故事 / 角色 IP）
3. **观众在哪看**？（B 站横屏 / 抖音竖屏 / 官网首页循环 / 发布会大屏）

## 风格方向

每个方向列出：适合什么产品、视觉、动效、字体、声音、在 Remotion 里的实现要点。

### 电影预告片（Vibe Coding 教程用过）
- 适合：想制造「大事件」感的产品、教程、平台型产品。
- 视觉：深色、体积光、胶片颗粒、暗角、宽银幕黑边，一个品牌主色 + 一个点睛色。
- 动效：静 → 爆发的强反差；镜头推拉、3D 透视、冲击闪白、屏幕震动、快切蒙太奇。
- 字体：粗黑几何标题（阿里妈妈数黑体 / 得意黑）+ 苹方正文。
- 声音：前奏压抑 → 渐强 → 重击爆发，大量 riser / whoosh / 低频冲击。
- 实现：`impulse` 做闪白与冲击缩放，`shake` 做震屏，CSS 3D（perspective + rotateX/Y）做镜头运动。

### Q 版卡通 / 吉祥物
- 适合：面向大众、年轻人、学生的工具和 App；有 IP 形象或可以设计一个。
- 视觉：高饱和糖果色、粗描边、圆角、大头小身角色、贴纸感元素、白色或浅色背景。
- 动效：弹性（`EASE.back` / Remotion `spring`）、挤压拉伸、角色表情切换、元素「蹦」出来，节奏轻快。
- 字体：圆体或手写感粗体（站酷快乐体、得意黑圆润场景、阿里巴巴普惠体 Heavy）。
- 声音：轻快尤克里里 / 口哨 / 电子 pop，音效用「啵」「叮」「嗖」。
- 实现：角色先用生图工具定一个主形象，再以它为参考生成多个表情/动作（保持同一角色），透明底 PNG；角色动作用 transform 做呼吸、跳跃、摇摆循环。

### 苹果发布会极简
- 适合：设计感强、定位高端的产品，硬件、专业软件。
- 视觉：纯白或纯黑大面积留白，单一焦点，超大标题，产品界面/实物居中，极细线条。
- 动效：缓慢、精准、克制；大字一词一词出现，界面平滑滑入，几乎没有闪烁和抖动。
- 字体：苹方 / SF 风格，大字号细字重对比。
- 声音：钢琴或氛围电子，少量精致音效。
- 实现：长时间的 `EASE.inOut` 缓动，一屏只放一件事；注意节奏底线仍然适用。

### 界面实录（产品巡礼）
- 适合：功能即卖点的 SaaS、效率工具、开发者工具。
- 视觉：真实界面截图放进设备框 / 浏览器框，放大镜聚焦、光标点击、高亮框。
- 动效：模拟真实操作——打字、点击、拖拽、结果出现；镜头跟随光标推近。
- 字体：界面本身的字体 + 简洁说明文字。
- 声音：轻电子，键盘声、点击声与操作逐一对齐。
- 实现：`typed()` 逐字打字；截图分层重建（背景 + 可动的卡片），比一整张静态截图生动得多。

### 手绘涂鸦 / 白板讲解
- 适合：讲清一个概念的产品、教育类、温暖亲和的品牌。
- 视觉：纸张纹理、手绘线条、马克笔色块、手写字。
- 动效：线条描绘（SVG stroke-dashoffset）、元素像被画出来、轻微抖动的逐帧感。
- 字体：手写体。
- 声音：原声吉他、笔触沙沙声。
- 实现：`@remotion/paths` 的 `evolvePath` 画线；用 `random()` + 帧号做「boiling line」抖动。

### 像素复古 / 8-bit 游戏
- 适合：游戏、开发者社区、极客向产品、趣味工具。
- 视觉：像素字、低分辨率色板、CRT 扫描线、游戏 UI（血条、经验值、关卡）。
- 动效：按帧跳变（不做平滑补间）、像素爆炸、「LEVEL UP」。
- 字体：像素字体（Zpix 等开源像素中文字体）。
- 声音：chiptune，8-bit 音效。
- 实现：把 `t` 量化到 12fps 再算动画，`image-rendering: pixelated`。

### 赛博朋克霓虹
- 适合：AI、安全、硬核技术产品。
- 视觉：黑底霓虹（品红 / 青）、故障（glitch）、扫描线、HUD 界面、代码雨。
- 动效：RGB 分离、闪烁、切片错位、HUD 数字滚动。
- 声音：暗黑合成器、故障音效。

### 杂志排版 / 瑞士平面
- 适合：内容型产品、媒体、品牌感强的产品。
- 视觉：网格系统、大字号对比、色块、照片裁切、编号。
- 动效：版块滑动推移、文字遮罩揭示、色块擦除转场。
- 声音：节奏感强的 lo-fi / 爵士 / house。

### 3D 黏土 / 玩具质感
- 适合：生活类、亲子、温暖可爱的产品。
- 视觉：黏土或塑料质感的 3D 场景与角色（生图工具出图），柔和阴影、浅景深。
- 动效：定格动画感（10~12fps 抖动）、弹跳。

### 国潮 / 水墨
- 适合：文化、国风、传统行业数字化产品。
- 视觉：水墨晕染、宣纸、印章、朱红点睛、竖排文字。
- 动效：墨迹扩散遮罩、卷轴展开、毛笔描字。

### 纯文字动效（Kinetic Typography）
- 适合：没有好素材、卖点靠一句话打动人的产品；也适合作为其它风格里的段落。
- 视觉：只有字，靠字号、字重、颜色、排列制造冲击。
- 动效：逐字弹出、缩放冲击、词与词互相挤开、跟着鼓点换字。

## 知识讲解类风格（科普、原理、深度解读）

> 风格清单参考自 [chengfeng-video-styles](https://github.com/Agentchengfeng/chengfeng-video-styles)（成峰 / AI产品自由，Apache-2.0），按本工具的画幅、时长和「真实素材为主」改写；讲解方法见 `讲解设计.md`。原项目是 10 秒、16:9、纯代码无素材的单知识点短片，这里每种都写了**放进 60 秒以上竖屏片**时怎么用。

这些风格不一定撑满全片：常见做法是全片一个主风格，原理段落换成下表里的某种画法（特斯拉深度版就是控制台 HUD 主风格 + 原理段落的扁平示意动画）。

| 风格 | 画面写法 | 适合讲 | 放进竖屏长片时 |
|---|---|---|---|
| 皮影戏 | 剪影布景、幕布透光、关节式动作 | 典故、历史故事、寓言 | 幕布竖着拉高，人物放中上；字幕在幕布下沿 |
| 等距流程 | 等距 2.5D 微缩场景，每个环节出编号标签，最后拉远连成一条线 | 流程、供应链、系统怎么运转 | 流程改成自上而下的 Z 字形；精细机器式主视觉可用项目 Skill `anatomy`（见下） |
| 比例尺对比 | 真实尺寸同屏摆放，镜头不断拉远 | 大小、距离、数量级 | 竖屏天然适合「越来越高」，纵向排列；比例必须按真实数据 |
| 白板手绘 | 白底黑马克笔一笔笔画出，红色强调 | 概念、边际效应、日常原理 | `evolvePath` 画线；真实截图可以像「贴在白板上」 |
| 汉字演变 | 电影感光影、龟甲青铜质感，大字标注朝代 | 文字、文化、词源 | 大字放中上，朝代标注放字下方 |
| 3D 拆解 | 爆炸图，部件分层飞开、引线标注，镜头绕转 | 产品结构、硬件、机器 | 部件纵向分层飞开；有官方拆解图时优先用真实图 |
| 像素典故 | 16 位像素风，按帧跳变 | 寓言、游戏化讲故事 | 同本菜单「像素复古」的实现 |
| 绘本科普 | 钢笔线 + 蜡笔涂色，线条微微抖动 | 儿童向、温暖的自然科普 | boiling line 抖动；配色偏暖 |
| 数学可视化 | 3Blue1Brown 式深色底、干净几何，图形真的移动拼合 | 公式、几何、算法 | 一次只推一个公式项；公式贴在刚演过的图形上 |
| 地图动画 | 古地图羊皮纸、淡墨山脉，朱红路线一路画过去，每站盖章 | 路线、传播、历史事件 | 地图竖向裁切跟随路线滚动；年份里程必须查证 |
| 数据信息图 | Kurzgesagt 式干净图形、等宽大数字，按对数拉远 | 数量对比、统计、增长 | 柱子纵向长高；数字全部带出处 |
| 扁平 MG | 纯色几何、无描边，镜头跟着一个主角走完流程 | 循环、过程、一个东西的旅程 | 主角放画面中线，镜头纵向跟随 |
| 卡点金句 | 120 BPM，每个词卡一拍，靠字号、遮罩切入、整屏换色出节奏 | 方法论、结论、口号 | 同本菜单「纯文字动效」，竖屏每行 4~6 字 |
| 漫画分格 | 黑白网点 + 一个红色，镜头在格间移动，拟声字、速度线、对话框 | 有冲突、有人物的故事（如「AI 拖住骗子」） | 竖屏改成上下分格；对话框可以装真实聊天截图 |
| 时间线 | 横向时间轴，镜头沿轴推进，节点依次点亮 | 发展史、事件经过 | 竖屏改成纵向时间轴，镜头向下推进 |

### 精细机器主视觉：`anatomy` 项目 Skill

本仓库在 `.claude/skills/anatomy/` 装了 [anatomy](https://github.com/wheresryan22/anatomy)（MIT）：把一个技术概念画成一台真实机器的精细等距 SVG（可交互，可加 WebGL 火焰、水波、光效）。它出的是**网页插图，不是视频**，用法：

1. 在工程目录外（如 `工程/out/anatomy/`）让它做一张图，它会生成 HTML 页面。
2. 用它自带的 `scripts/drive.mjs` 按时间截帧，或用 `shot.py` 截静帧，导出成一段几秒的素材。
3. 素材按 `src/ui/Clip.tsx` 的方式放进片子，当一个原理镜头。

注意：它做一张小图就接近 1 小时、复杂的 2~4 小时，额度消耗大，只用在一支片子最关键的那一个原理镜头；它不画人物和精确地图。只在克隆用法的工作区里可用，不会被复制进新项目。

### 系列视频：先写风格圣经和组件库

同一个账号连续做一个系列（如 `#vibe知识大赏` 每集讲一个概念）时，第一集开工前先定下这两样，之后每集照用，观众一眼认得出是同一个节目：

1. **风格圣经**：写进第一集的 `需求确认.md`，并单独存一份 `<输出目录>/<系列名>风格圣经.md`。内容：配色（每种颜色的含义）、字体与字号层级、片头片尾格式、常驻元素（角标、集数、进度标识）、转场方式、配乐与音色、旁白口吻、每集固定结构（如「钩子 → 三个反常识点 → 一句话结论」）。
2. **组件库**：第一集工程里把常驻元素、标题卡、字幕、解释卡、数据卡做成独立组件，放在 `src/ui/`。后续每集从 template 新建工程后，把这些组件和 `theme.ts`、`fonts.json` 拷过去，不重新设计。
3. 每集的选题、形象、分镜仍按 `讲解设计.md` 现写；系列统一的只是包装，不是内容。
4. 系列内后续几集不必重新出风格样片，需求问询里风格一题直接写「沿用系列风格圣经」；用户想换风格时再出样片。

## 叙事结构

同样是菜单。给用户推荐时要写成**这个产品的具体版本**（每段具体放什么）。

| 结构 | 流程 | 适合 |
|---|---|---|
| 痛点 → 转折 → 证明 → 号召 | 「你是不是也……」→「现在只需要……」→ 功能/作品/数据轰炸 → 网址 | 大多数工具与教程（Vibe 用的是它的变体：钩子 → 一句话变产品 → 作品 → 内容全景 → 免费 → logo） |
| 一镜到底产品巡礼 | 镜头连续穿过产品各个界面 | 界面好看、功能连贯的 SaaS |
| 角色故事 | 一个角色遇到问题 → 用了产品 → 生活改变 | Q 版、面向大众的 App |
| 前后对比 | 同一件事：用之前 vs 用之后，左右分屏或重演 | 效率提升类 |
| 数字轰炸 | 一连串震撼数字 + 画面佐证 | 数据亮眼的平台、开源项目 |
| 倒计时 / 挑战 | 「10 分钟做出一个 App」计时推进 | 强调快和简单的产品 |
| 用户证言拼贴 | 真实评价、截图、弹幕飞过 | 口碑好的产品（证言必须真实） |
| 事件 / 爆料 | 一句话说清发生了什么 →「到底怎么回事」→ 怎么被发现的 → 怎么验证 → 晒出来的成果 → 现在的官方状态 → 你可以怎么做 | 新模型灰度、产品泄露、刚出圈的事件（Claude Fable 5.5 用的是它） |

**悬念不能代替交代**：第一版 Fable 用「标着 Fable 5.1，答的却不是它？」开场，懂的人觉得妙，不懂的人完全不知道在说什么。先用一句大白话交代事件（「Fable 5.5 还没发布，就有人提前用上了」），悬念放在「怎么回事」之后。每段旁白开头最好能接上一段的结尾（「怎么验证？」「换上的人开始晒作品了」），观众才跟得上。

## 通用质感清单（无论什么风格都要考虑）

- **风格是包装，真实截图是主角**：任何风格都要给真实界面截图和真实作品留出主画面（浏览器窗口框、手机框、漫画分格、像素屏幕……都可以是装截图的容器），风格元素负责转场和氛围。
- **开场直接进入痛点或亮点**：风格铺陈不能占用前 3 秒。

- 画面有**层次**：背景层 / 主体层 / 前景点缀，不要一张图贴满屏。
- **动静结合**：每个场景至少一个持续的微运动（缓推、漂浮、呼吸），避免死帧。
- **转场有设计**：与风格匹配（冲击闪白 / 擦除 / 遮罩 / 物体穿越），和音乐重拍对齐。
- **文字与背景对比足够**：浅色背景上的浅色渐变字、和光效重叠的白字都是踩过的坑。
- **最高潮必须有网址/CTA**。
